# 카카오알림 전송

카카오톡 비즈니스 채팅에서 학생들에게 메시지를 전송하는 데스크탑 앱입니다.

## 실행 방법

### 필요 사항
- Python 3.11 이상 ([다운로드](https://www.python.org/downloads/))

### 첫 실행
1. 이 저장소를 다운로드 (초록색 **Code** 버튼 → Download ZIP)
2. 압축 해제 후 폴더 안의 **`run.bat`** 더블클릭
3. 자동으로 패키지 및 브라우저 설치 (최초 1회, 수분 소요)
4. 앱이 실행되면 **카카오 로그인** 버튼 클릭

### 두 번째 실행부터
**`run.bat`** 더블클릭하면 바로 앱 실행됩니다.

## 주요 기능

- 이름 검색으로 내 담당 학생 찾기
- 학생 선택 후 메시지 전송
- 자주 보내는 학생 **그룹** 저장 / 관리
- **예약 전송** — 날짜·시간 지정
- 세션 자동 유지 (한 번 로그인하면 재사용)

## 참고

- 전송 전 **카카오 비즈니스** 관리자 추가인증이 필요할 수 있습니다.
  - Chrome에서 `business.kakao.com` 접속 → 채팅 목록 → **관리자 추가인증** 버튼 클릭 → 휴대폰 인증 완료
  - 앱에서 **카카오 로그인** 버튼을 다시 클릭하면 인증이 반영됩니다.
